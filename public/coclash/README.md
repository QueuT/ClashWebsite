# Colorado Clash media archive

Public images collected from the official club site and its Wix media sitemap.

- `colorado-clash-crest.png`: home-page crest.
- `mascot-*.png`: the four original mascot marks shown on the home page.
- `home-team-photo-*`: team photos identified on the home page.
- `team-mark-*.png`: additional artwork identified on the Teams page.
- Media-ID-named files: unique images from the public store and portfolio image sitemaps.
- `page-image-urls.txt`: source URLs for the named crest, mascot, home-page, and Teams-page assets.
- `sitemap-image-urls.txt`: image URLs extracted from the public sitemap index's store and portfolio sitemaps. Duplicate media IDs are retained in the manifest but downloaded once.
- `page-crawl-image-urls.txt`: additional unique media found across the 12 public pages listed in the page sitemap.

Source: https://www.coclashvbc.com/

This archive covers the image assets indexed in the public store and portfolio sitemaps, plus unique image sources found across the 12 public pages in the page sitemap. Instagram posts and video files are not mirrored here. Confirm usage rights before redistributing the archived media outside this club project.
